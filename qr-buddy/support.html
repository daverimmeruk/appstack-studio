QR Buddy — Questions & Answers

1. Why doesn't the app ask for the camera?

The camera screen is Google's code scanner, part of Google Play services. It reads the code and hands the app only what the code says, so the app itself doesn't need camera permission.

2. The scanner doesn't open, or says it isn't ready.

The first time, Android may need a moment and an internet connection to get the scanner ready. Make sure Google Play services is up to date, connect once, then try again. You can also scan a code in a screenshot or photo with 🖼️ Scan a code in a photo.

3. Is a link safe to open?

QR Buddy shows the website name and the whole address first and checks the address for warning signs (not https, shortened links, numbers instead of a name, look-alike letters, an "@" before the name, names with many parts, names ending in .zip or .mov). No warning isn't proof a site is safe: only open links from people and places you trust, and never type passwords or card details on a site you reached from a code you weren't expecting.

4. How do guests join my Wi-Fi with a code?

On ✏️ Make, tap 📶 Wi-Fi, type the network name and password and tap Make. Show the code on screen, share it as a picture, or with Pro print a card with the code large and the details under it. Check it by scanning it with another phone first.

5. Where are my scans kept?

Only in the app's own storage on your phone. They are not in Android's backups. Free keeps your newest 20 scans and 5 saved codes; Pro keeps them all.

6. I bought Pro on another phone. How do I get it back?

Use the same Google account, tap GO PRO at the top, then Restore purchase.
