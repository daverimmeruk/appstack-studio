❓ Frequently Asked Questions (FAQ)


Q1: Who pays for a check code?

Whoever makes the code pays for it: 1 credit makes one check code, or Pro gives unlimited credits. Typing in a code you were sent is always free, so the other person only needs to install the free app.

Q2: My code was answered, but I can't see the report.

Reports are collected when you open the app. Open Phone Check Buddy and look under 📨 My check codes, or tap 🔄 Check for report. Your phone needs the internet. Earlier codes and their reports are in 📜 History: tap 📋 Open report there. If 📜 History says the code expired, no report arrived within 7 days: make a new code.

Q3: It says "That code isn't right".

Codes have 12 letters and numbers, like 7K4M-29QX-D3HZ. The letters O, I and L and the numbers 0 and 1 are never used. The last character checks the others, so a mistyped or swapped character is caught straight away. Capitals, spaces and dashes don't matter.

Q4: It says "No check found".

The code has already been used, is more than 7 days old, or was never made. Each code works once. Ask for a new code.

Q5: How do I know the report is genuine?

The report is signed inside the phone's security chip, and Phone Check Buddy checks that signature against Google's certificates. If the report was changed, didn't come from a real phone's security chip, or its keys were withdrawn by Google, the report isn't shown at all. A phone with modified software or an unlocked bootloader still gets its report, with a ⚠️ or ❌ warning at the top.

Q6: Why does a back camera show ℹ️ instead of ✅?

During the automatic test the phone lies on its back, so the back cameras face the table. If a back camera sends pictures but only sees darkness, it is shown as working but not judged (ℹ️), not as failed. To judge the back cameras' pictures, run ▶ Start full test and point the phone at something with detail.

Q7: A test says "Not tested".

The step was skipped, a permission wasn't allowed, or the feature was switched off (for example Bluetooth). Switch on Bluetooth, Wi-Fi and Location before the test, and tap Allow when Android asks for the microphone, camera, location or nearby devices. A report made by answering or proving with a code always lists the hands-on tests (flashlight, proximity sensor, touch screen, screen colours, buttons and charging) as not tested, because they need a person.

Q8: Can it check whether a phone is stolen or blocked?

No. Android doesn't let apps read the IMEI, so Phone Check Buddy can't check whether a phone is reported lost or stolen, or blocked by a network. Check the IMEI with the network or a checking service.

Q9: How is battery health worked out?

Android doesn't tell apps the battery's original size. Enter it with 🔋 (from the box or the maker's specification, for example 4000 mAh) and Phone Check Buddy estimates the health from the charge Android reports. It is an estimate.

Q10: What is sent when I use a check code?

Only the report (the spec sheet and test results) and the security certificates that prove it is genuine, locked with the code so nobody else can read it. It is deleted as soon as the code is used, and can't be opened after 7 days. Photos, messages, contacts, accounts, files and your location are never read or sent. See our Privacy Policy.

Q11: How do I buy credits or Pro, and get them back?

Tap GO PRO at the top of the app, or make a code and choose Buy 1 credit or Buy Pro. Both are one payment through Google Play, with no subscription; the price is shown by Google Play. Pro, or a credit you paid for but haven't used, comes back by itself when you open the app on this or another phone with the same Google account. There's no Restore button to tap.
